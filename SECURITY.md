# Security Policy

## Supported Versions

We release patches and security fixes for the current major release:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The Resurgam SEO team takes security seriously. If you discover a vulnerability, please do **NOT** open a public issue.

### Disclosure Process

1. Email vulnerability details to [security@resurgam.digital](mailto:security@resurgam.digital) (or submit via [GitHub Private Vulnerability Reporting](https://github.com/teamresurgam/resurgam-seo-next/security/advisories/new)).
2. Include:
   - A description of the issue and potential impact.
   - Minimal reproduction code or proof of concept.
   - Package version and Next.js / Node.js version.
3. We will acknowledge receipt within 48 hours and provide an estimated timeline for remediation.
4. Once resolved, we will publish a coordinated advisory and release a patched version on npm.
