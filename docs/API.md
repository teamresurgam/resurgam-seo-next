# API Reference: `@resurgam/seo-next`

## Initialization

### `createResurgamSEO(config: ResurgamSEOConfig): ResurgamSEOClient`

Creates a new client instance configured for your WordPress CMS and Next.js frontend URLs.

```typescript
import { createResurgamSEO } from '@resurgam/seo-next';

export const seo = createResurgamSEO({
  wordpressUrl: process.env.WORDPRESS_API_URL!, // e.g. https://cms.example.com
  apiUrl: process.env.RESURGAM_SEO_API_URL,      // optional override
  siteUrl: process.env.NEXT_PUBLIC_SITE_URL!,   // e.g. https://www.example.com
  apiKey: process.env.RESURGAM_SEO_API_KEY,      // optional draft preview key
  defaultRevalidate: 3600,                      // 1 hour Next.js ISR cache
  trailingSlash: false,
});
```

### Configuration Options (`ResurgamSEOConfig`)

| Option | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `wordpressUrl` | `string` | **Yes** | — | Root WordPress URL (e.g. `https://cms.example.com`). |
| `siteUrl` | `string` | **Yes** | — | Public frontend site URL (e.g. `https://www.example.com`). |
| `apiUrl` | `string` | No | `${wordpressUrl}/wp-json/resurgam-seo/v1` | Custom override for REST API endpoint base. |
| `apiKey` | `string` | No | `undefined` | Secret API key passed via `X-Resurgam-Api-Key` and `Authorization: Bearer`. |
| `previewSecret`| `string` | No | `undefined` | HMAC secret for verifying preview requests. |
| `timeoutMs` | `number` | No | `8000` | Network request timeout in milliseconds. |
| `defaultRevalidate`| `number \| false` | No | `3600` | Next.js fetch revalidation interval in seconds. `false` disables cache (`no-store`). |
| `defaultTags` | `string[]` | No | `['resurgam-seo']` | Default Next.js cache tags for tag-based on-demand revalidation. |
| `trailingSlash`| `boolean` | No | `undefined` | Enforces trailing slash (`true`) or removes trailing slash (`false`) on canonical URLs. |

## Client Methods (`ResurgamSEOClient`)

### `seo.generateMetadata(queryOrId, options?): Promise<Metadata>`

Transforms actual WordPress SEO metadata into a Next.js App Router compatible `Metadata` object.

```typescript
export async function generateMetadata({ params }): Promise<Metadata> {
  return seo.generateMetadata({ slug: params.slug });
}
```

**Parameters**:
- `queryOrId`: `SEOQueryParams | string | number`
  - Number: Treated as WordPress post or term ID (`{ id: 123 }`).
  - Path string: Starting with `/` treated as frontend URL (`{ url: '/about-us' }`).
  - Slug string: Treated as content slug (`{ slug: 'about-us' }`).
  - Object: `{ id?: number, slug?: string, type?: string, url?: string, preview?: boolean, token?: string }`.
- `options`: Optional `FetchOptions` (`revalidate`, `tags`, `cache`, `headers`, `signal`).

**Behavior**: Strictly returns actual metadata returned by the Resurgam SEO WordPress plugin. Never generates fallback or placeholder values. If the API fails, a descriptive error is thrown.

---

### `seo.getMetadata(queryOrId, options?): Promise<WordPressSEOData | null>`

Fetches raw normalized WordPress SEO metadata. Returns `null` when content is not found (404). Throws `WordPressAPIError` on API, network, or server failures.

```typescript
const seoData = await seo.getMetadata({ slug: 'about-us' });
if (!seoData) {
  notFound();
}
```

---

### `seo.getSchema(queryOrId, options?): Promise<Record<string, unknown> | null>`

Retrieves the structured data JSON-LD graph generated by WordPress for the requested entity.

```typescript
const schema = await seo.getSchema({ slug: 'about-us' });
```

---

### `seo.generateSitemap(options?): Promise<NextSitemapEntry[]>`

Fetches sitemap entries from the WordPress headless sitemap endpoint (`/sitemap`), rewrites all canonical targets to the public frontend `siteUrl`, and formats them for `app/sitemap.ts`. Throws a descriptive error if the WordPress API fails.

```typescript
// app/sitemap.ts
import { seo } from '@/lib/seo';
import type { MetadataRoute } from 'next';

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  return seo.generateSitemap({
    type: 'all',
    perPage: 100,
  });
}
```

---

### `seo.generateRobots(options?): NextRobotsConfig`

Generates robots.txt rules for `app/robots.ts`.

```typescript
// app/robots.ts
import { seo } from '@/lib/seo';
import type { MetadataRoute } from 'next';

export default function robots(): MetadataRoute.Robots {
  return seo.generateRobots({
    disallow: ['/api/', '/admin/', '/_next/'],
  });
}
```

## React Server Component

### `<ResurgamJSONLD schema={schema} id="custom-id" nonce="csp-nonce" />`

Safely serializes and injects structured JSON-LD into the page.

- Escapes HTML injection characters (`<`, `>`, `&`).
- Deduplicates schema nodes with duplicate `@id` or `@type` signatures.
- Omits empty or invalid graphs cleanly.
